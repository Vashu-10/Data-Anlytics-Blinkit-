# Data-Anlytics-Blinkit-
1️. Project Title / Headline
Blinkit Sales & Outlet Performance Analysis Dashboard (Power BI)

2️. Short Description and Purpose
This project presents an interactive sales analytics dashboard built using Power BI to analyze Blinkit's grocery retail dataset. The dashboard provides insights into total sales, average sales, item distribution, outlet performance, and product categories across different outlet sizes and locations.
The report includes dynamic filtering using slicers, KPI indicators, category-wise analysis, and outlet-level comparisons to support data-driven business decisions.

The primary objective of this project is to:
-Analyze overall sales performance
-Identify high-performing outlet types and locations
-Understand customer purchasing trends
-Compare item categories and fat content contribution
-Evaluate outlet establishment trends over time
-Provide actionable insights for retail growth strategy

This dashboard helps stakeholders quickly monitor KPIs and make strategic decisions regarding expansion, inventory planning, and outlet performance improvement.

3️. Tech Stack

Power BI Desktop – Dashboard development & visualization

Python (Pandas - Optional Analysis) – Data preprocessing & EDA

-Key Concepts Applied

4. Features and Dashboard Details
- KPI Cards
The dashboard includes the following key performance indicators:
Total Sales: $1.20M
Average Sales: $141
Number of Items: 8,523
Average Rating: ~4

These KPIs dynamically update based on slicer selections.

-Slicers (Interactive Filters)
Users can filter data dynamically using:
Outlet Location Type (Tier 1 / Tier 2 / Tier 3)
Outlet Size (Small / Medium / High)
Item Type
Outlet Type

This makes the report fully interactive and dynamic.
